CRICKET LIVE SCORE V8 — VERY SIMPLE SETUP

1) Root folder me api-key.js file already hai.
2) api-key.js open karo.
3) Is line me quotes ke andar apni FREE CricketData API key paste karo:
   export const CRICKETDATA_API_KEY = 'PASTE_KEY_HERE';
4) Save karo.
5) Deploy/restart karo.

api-key.js kaha hai?
Ye index.html ke same level par hai:
cricket-v8/
  index.html
  api-key.js   <-- YAHAN KEY PASTE KARNI HAI
  app.js
  styles.css
  server.mjs
  api/

SECURITY:
Agar GitHub repo PUBLIC hai to real key api-key.js me commit mat karo.
Vercel Dashboard > Settings > Environment Variables > CRICKETDATA_API_KEY me key dalo.
Private repo me file method use kar sakte ho.
